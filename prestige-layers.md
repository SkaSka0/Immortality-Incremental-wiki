# Prestige Layers

> Each prestige layer = the currency gained from resetting + its own upgrade board (combined here since they always come as a pair). For the Mark catalog (gacha items per layer), see `marks-database.md`. For upgrade boards that stand alone outside a prestige layer (e.g. Qi Upgrades), see `upgrades.md`.

Reset groups (cascading once each group completes): **Group 1 = Insight → Essence → Soulfire** (resetting at Soulfire resets all three). The next groups are expected to follow the same pattern, 3 layers per group. Note: this cascading reset grouping is separate from the Map grouping below — a single Map can contain more than one reset group (e.g. Map 1 has 4 layers: Insight-Essence-Soulfire is one reset group, and Karma is likely the start of the next reset group).

---

## Insight
*Map 1 — layer 1*

- **Reset:** Realm, Qi, and Qi Upgrades → converted into **Insight** points
- **Unlock requirement:** Realm **Foundation V [#10]**
- **Example gain on reset (snapshot):** +253.94Uvg Insight
- **Use of Insight points:** level up Insight Upgrades (below) + roll gacha for **Mark of Insight** (250 Insight/roll — see `marks-database.md`)
- **Reset effect:** cascading — resetting at the group's last layer (Soulfire) will also reset Insight

### Insight Upgrades

| Upgrade | Level (snapshot) | Effect at MAX |
|---|---|---|
| More Insight | 75/75 (MAX) | x1.62M Insight |
| More Qi | 75/75 (MAX) | x130K Qi |
| More Luck | 75/75 (MAX) | x18.53K Luck |
| More Mark Speed | 5/5 (MAX) | x1.5 Mark Speed |
